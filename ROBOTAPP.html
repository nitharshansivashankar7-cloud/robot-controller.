Starter firmware – beginner guide

Firmware is the small program uploaded to your robot's board. It tells the motor driver what to do when this app sends a command.

Check compatibility before copying
  • This starter sketch is for an Arduino Uno or Nano connected by USB serial.
  • It expects an L298N motor driver and the pin numbers shown in the code.
  • Choose USB serial in the app and set the baud rate to 115200.
  • Bluetooth LE and Wi-Fi WebSocket need different firmware; this sketch does not implement those connections.
  • The servo sliders are visible, but servo control is not implemented in this starter sketch.
App commands
  • F / B / L / R – forward, backward, left and right.
  • S – stop. Releasing a direction button sends this command.
  • V plus a number – set speed from 0 to 255, for example V120.
  • LED:1 / LED:0 – switch the board's built-in LED on or off.
  • PING – test communication; the board replies PONG.
Safety: Test with the wheels raised and the robot secured. Start at low speed and keep the STOP control available. Check your board and motor-driver documentation for wiring and power requirements.
What do the code sections mean?
  • Pin numbers: Arduino pins connected to the L298N.
  • drive(...): sets motor direction and speed.
  • setup(): starts serial communication and prepares the pins.
  • loop(): reads commands sent by the app.
  • Speed: 0–255 is the PWM output range.
